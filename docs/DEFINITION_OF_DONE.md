# Definition of done

For every future task:

- Requirements are implemented and assumptions are documented.
- Authentication, authorization, validation, and safe error behavior are checked where relevant.
- Relevant tests are added and pass.
- Lint, typecheck, tests, and production build pass.
- No secrets are introduced.
- Documentation and contracts are updated.
- Responsive and accessibility impact is reviewed.
- Reviewer-facing text is concise, grammatical, and consistent.
